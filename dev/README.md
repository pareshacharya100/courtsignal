# Dev notes

Persistent task notes for multi-session work, so context survives Claude Code resets.
`dev/active/<task>/` holds `<task>-plan.md`, `<task>-context.md` and `<task>-tasks.md`.
Create with `/dev-docs`, refresh with `/dev-docs-update`. No secret values here.
Pattern adapted from diet103/claude-code-infrastructure-showcase (MIT; see .claude/UPSTREAM-LICENSE).
